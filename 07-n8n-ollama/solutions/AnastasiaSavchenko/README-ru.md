Кейс № 7

Цель:
Дать команде ML-инженеров возможность не зависеть от внешних веб-сервисов, а также модифицировать и устанавливать свои локальные модели и работать с ними.

Чекпоинты:
Установить Postgres, Redis, n8n, Ollama.
Подключить к n8n установленные Postgres и Redis (для решения задачи используйте Docker Compose).
Добавьте контейнер с Ollama в ваш манифест Docker Compose, скачайте любую подходящую модель LLM из библиотеки Ollama (советуем Qwen 2.5 на 3b параметров). ollama run qwen2.5:3b
Настройте креды в n8n – добавьте Ollama в Credential n8n.
Создайте новый воркфлоу:
Создать и настроить ноду OpenAI Chat Model, указав endpoint Ollama и выбрать скачанную ранее модель.
Создать воркфлоу Chat Message → AI Agent → Chat Model (Ollama).
Добавить к AI Agent память (redis/postgres)


Инструкция: https://github.com/inview-club/devops-cases/blob/main/07-n8n-ollama/

Призовой Кейс

Цель:
Построить базовый AIOps‑ и ChatOps‑слой поверх Prometheus, который ускоряет реакцию на инциденты, уменьшает рутину для дежурных и создает основу для дальнейшей автоматизации (корреляция алертов, авто‑диагностика, рекомендации по устранению).

Чекпоинты:
Разверни Node Exporter, Prometheus и Alertmanager. (для решения задачи используйте Docker Compose);
Выбери алерты с сайта Awesome Prometheus Alerts и добавь их в Prometheus;
Создай в n8n новый workflow с Webhook‑нодой, принимающей payload от Alertmanager;
Настрой в Alertmanager отправку алерта в Webhook n8n;
Добавь шаг, который парсит payload алерта и извлекает ключевые параметры;
Добавь шаг с LLM‑нодой, который по данным алерта формирует человекочитаемое описание инцидента и краткое резюме для сообщения в чат;
Получить креды от Бота (@inview_bot) через команду /workshop.
Добавь шаг, который создаёт задачу в GitLab (https://gitlab.inview.team/n8n/incidents) с нужными полями и контекстом;
Добавь шаг, который отправляет в чат Telegram уведомление с резюме инцидента и ссылкой на задачу.
